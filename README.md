# 🏋️‍♂️ Landing Page para Personal Trainer

## 📌 Sobre o Projeto
Este projeto consiste em uma **landing page moderna, responsiva e focada em conversão**, desenvolvida para personal trainers que desejam transformar visitantes em alunos.

A página foi projetada com foco total em **usuários mobile**, considerando que a maior parte do tráfego vem do Instagram.

---

## 🎯 Objetivo
Criar uma página simples, rápida e estratégica que:

- Aumente a conversão de visitantes em clientes  
- Direcione o usuário diretamente para o WhatsApp  
- Apresente serviços de forma clara e organizada  
- Transmita autoridade e profissionalismo  

---

## 🚀 Funcionalidades

- 📱 Design 100% responsivo (mobile-first)  
- 💬 Botão de contato direto via WhatsApp  
- 🧠 Estrutura pensada para conversão  
- 🖼️ Seção de prova social (antes/depois e depoimentos)  
- 📋 Apresentação clara dos serviços  
- ⚡ Carregamento rápido e otimizado  
- 🎨 Interface moderna e clean  

---

## 🧱 Estrutura da Página

- **Hero Section**  
  Apresentação principal com CTA direto  

- **Prova Social**  
  Resultados reais e depoimentos  

- **Serviços**  
  Presencial, online e planos personalizados  

- **Benefícios**  
  Diferenciais e proposta de valor  

- **Sobre o Personal**  
  Autoridade e confiança  

- **CTA Final**  
  Chamada forte para ação

## 📱 Foco em Mobile

Este projeto foi desenvolvido com abordagem **mobile-first**, priorizando:

- Navegação simples com uma mão
